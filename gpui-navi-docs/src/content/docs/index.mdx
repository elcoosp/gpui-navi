Navi is a file-based router for Rust UI applications. It is **not tied to any single UI framework**: the routing engine, loaders, guards, cache, and devtools live in framework-free crates, and all rendering seams are delegated to [quoin](https://github.com/elcoosp/quoin) — one reactive core, many frontend backends. The same route table, components, and devtools panel run unmodified on GPUI, Dioxus, Leptos, Xilem, and Floem.

## What you get

- **File-based routing** — define routes intuitively through the filesystem; `navi-codegen` generates a type-checked route tree at build time.
- **Nested layouts** — hierarchical layouts powered by `<Outlet>`.
- **Loaders** — data fetching with caching, stale-time, and garbage collection, backed by [rs-query](https://github.com/elcoosp/rs-query).
- **Suspense boundaries** — granular loading states with `Awaited` and `SuspenseBoundary`.
- **`beforeLoad` guards** — robust route protection with redirect and not-found results.
- **Navigation blockers** — async and sync guards that prevent data loss from unsaved changes.
- **Scroll restoration** — automatic memory and restoration of scroll positions, keyed by path plus normalized query.
- **Navigation transactions** — batch `Push`, `Replace`, `Back`, `Forward`, and `Go` operations applied atomically with a single re-render.
- **Devtools** — inspect routes, cache, timeline, and state directly inside your app, on every supported framework.
- **Link preloading** — `Render`, `Intent` (hover plus delay), and `Viewport` strategies with per-href deduplication.

## Frameworks

Selecting a framework is a feature flag on your crate. There is nothing GPUI-specific inside the router itself.

| Framework | quoin feature | Status |
| :--- | :--- | :--- |
| **GPUI** | `gpui` | ✅ first-class — devtools panel, keybindings, `run_app!` host |
| **Dioxus** | `dioxus` | ✅ first-class — Dioxus desktop (wry/tao window) |
| **Leptos** | `leptos` | ✅ first-class — CSR, `wasm32-unknown-unknown` |
| **Xilem** | `xilem` | ✅ first-class — Xilem main, rebuild-pump refresh |
| **Floem** | `floem` | ✅ first-class — Floem main, reactive bridge |
