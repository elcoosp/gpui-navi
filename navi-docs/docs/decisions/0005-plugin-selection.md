# 0005 — Plugin selection

**Status:** Accepted
**Date:** 2026-11-08

## Context

The Starlight plugin ecosystem offers several "bells and whistles" plugins.
Each one added must earn its place on a Navi docs site built on Astro 7.4 /
Starlight 0.42, under a zero-warning release gate.

## Decision

**Installed:**

| Plugin | Why |
| :--- | :--- |
| `starlight-links-validator` | Fails the build on broken internal links — the cheapest guarantee that the Diátaxis cross-linking stays correct as content grows. |
| `starlight-image-zoom` | Click-to-zoom on content images; useful for the route-tree file trees and any future screenshots. |

**Omitted, with reasons:**

| Plugin | Reason |
| :--- | :--- |
| `starlight-typedoc` | Generates API docs from TypeScript source. Navi is a Rust workspace — its API surface is documented by hand in `reference/` from the crate sources. Nothing for typedoc to consume. |
| `starlight-openapi` | Navi ships no OpenAPI specification. |
| `starlight-blog` | The changelog is maintained in the source repository (`CHANGELOG.md`, generated by git-cliff). Duplicating it as a blog section would create a second source of truth to keep in sync. |
| `starlight-versions` | The plugin is early development; Navi docs are single-version at this point. Revisit when Navi publishes versioned releases. |
| `starlight-heading-badges` | The docs currently mark experimental behavior inline with `<Aside>` callouts (e.g. `Viewport` preloading), which carries more nuance than a badge. |
| DocSearch (`@astrojs/starlight-docsearch`) | Requires an approved Algolia DocSearch application. **Pagefind — Starlight's built-in zero-config search — stays enabled** as the search solution. |

## Consequences

- Revisit the omitted plugins if Navi publishes to crates.io (versioned
  docs), gains an OpenAPI surface (it will not, it is not a web API), or the
  changelog moves into the docs site.
- Search is Pagefind today; if DocSearch is ever approved, it replaces — not
  supplements — Pagefind per Starlight's guidance.
