Vous obtenez automatiquement la restauration du défilement avec Navi : le routeur mémorise les positions de défilement au fur et à mesure que l'utilisateur navigue dans l'application et les restaure lors des visites de retour.

## Comment les clés fonctionnent

Les positions sont indexées par **chemin plus requête normalisée**. `/users?sort=asc` et `/users?sort=desc` mémorisent des positions distinctes, donc deux vues triées de la même liste ne se disputent pas un décalage. Le cache est borné en capacité avec une éviction en O(1), donc les sessions longues ne font pas croître la mémoire sans limite.

## Désactiver

Deux niveaux de désactivation existent :

| Niveau | Mécanisme |
| :--- | :--- |
| Navigation complète | Passez `reset_scroll: true` sur un `Link` pour commencer la position cible depuis le haut. |
| Par appel de navigation | `NavigateOptions.reset_scroll` fait la même chose pour la navigation programmatique. |

<Code lang="rust" code={`use navi_router::components::Link;

Link::new("/dashboard")
    .reset_scroll(true)
    .child("Dashboard (from the top)")
    .build()`} />

## Monter le composant

Le composant `ScrollRestoration` attache un nœud de suivi du défilement à votre UI. Donnez-lui un identifiant de handle :

<Code lang="rust" code={`use navi_router::components::ScrollRestoration;

ScrollRestoration::node("main-scroll").build()`} />

`ScrollRestoration::set_capacity(capacity)` borne combien de positions mémorisées sont conservées à la fois.
