Navi est un routeur basé sur les fichiers pour les applications UI Rust. Il **n'est lié à aucun framework UI unique** : le moteur de routage, les loaders, les gardes, le cache et les devtools vivent dans des crates indépendants du framework, et toutes les coutures de rendu sont déléguées à [quoin](https://github.com/elcoosp/quoin) — un seul cœur réactif, plusieurs backends frontend. La même table de routes, les mêmes composants et le même panneau de devtools s'exécutent sans modification sur GPUI, Dioxus, Leptos, Xilem et Floem.

## Ce que vous obtenez

- **Routage basé sur les fichiers** — définissez les routes intuitivement via le système de fichiers ; `navi-codegen` génère un arbre de routes vérifié à la compilation.
- **Layouts imbriqués** — layouts hiérarchiques propulsés par `<Outlet>`.
- **Loaders** — récupération de données avec cache, stale-time et garbage collection, propulsés par [rs-query](https://github.com/elcoosp/rs-query).
- **Frontières de suspense** — états de chargement granulaires avec `Awaited` et `SuspenseBoundary`.
- **Gardes `beforeLoad`** — protection de routes robuste avec résultats de redirection et de not-found.
- **Bloqueurs de navigation** — gardes synchrones et asynchrones qui préviennent la perte de données dues à des modifications non enregistrées.
- **Restauration du défilement** — mémorisation et restauration automatiques des positions de défilement, indexées par chemin plus requête normalisée.
- **Transactions de navigation** — regroupez les opérations `Push`, `Replace`, `Back`, `Forward` et `Go` appliquées atomiquement avec un seul re-rendu.
- **Devtools** — inspectez les routes, le cache, la timeline et l'état directement dans votre application, sur chaque framework pris en charge.
- **Préchargement de liens** — stratégies `Render`, `Intent` (survol plus délai) et `Viewport` avec déduplication par href.

## Frameworks

Sélectionner un framework est un drapeau de fonctionnalité sur votre crate. Il n'y a rien de spécifique à GPUI à l'intérieur du routeur lui-même.

| Framework | Fonctionnalité quoin | Statut |
| :--- | :--- | :--- |
| **GPUI** | `gpui` | ✅ première classe — panneau devtools, raccourcis, hôte `run_app!` |
| **Dioxus** | `dioxus` | ✅ première classe — Dioxus desktop (fenêtre wry/tao) |
| **Leptos** | `leptos` | ✅ première classe — CSR, `wasm32-unknown-unknown` |
| **Xilem** | `xilem` | ✅ première classe — Xilem main, rafraîchissement par pompe de reconstruction |
| **Floem** | `floem` | ✅ première classe — Floem main, pont réactif |
