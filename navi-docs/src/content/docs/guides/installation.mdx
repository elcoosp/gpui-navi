You add Navi to a Rust UI application in three steps: declare the crates, select your framework through a quoin feature, and wire route-tree generation into `build.rs`.

## Prerequisites

- Rust 1.85+ (edition 2024).
- A UI framework supported by quoin: GPUI, Dioxus, Leptos, Xilem, or Floem.

## 1. Add the crates

<Tabs>
  <TabItem label="Cargo.toml">
<Code lang="toml" code={`  [dependencies]
  navi-router = { path = "../navi/navi-router" }
  navi-macros = { path = "../navi/navi-macros" }
  quoin      = { path = "../quoin/quoin", features = ["gpui"] }`} />
  </TabItem>
  <TabItem label="cargo add">
<Code lang="bash" code={` cargo add navi-router --path ../navi/navi-router
 cargo add navi-macros --path ../navi/navi-macros
 cargo add quoin --path ../quoin/quoin --features gpui`} />
  </TabItem>
</Tabs>

<Aside type="note">
  The quoin and rs-query crates Navi builds on are consumed as local path
  dependencies today: the workspace expects the `quoin` and `rs-query` clones
  to sit side by side with the `navi` clone (a `workspaces/` directory
  containing all three). Once quoin and rs-query publish releases carrying the
  required changes, these become plain version dependencies. The examples in
  the repository already use this layout.
</Aside>

## 2. Select your framework

The framework is a feature flag on quoin. The route table, components, loaders, and devtools do not change when you switch.

| Framework | quoin feature | Bootstrap style |
| :--- | :--- | :--- |
| GPUI | `gpui` | `run_app!(App)` |
| Dioxus | `dioxus` | `LaunchBuilder::desktop().launch(app)` |
| Leptos | `leptos` | `mount_to_body` on `wasm32-unknown-unknown` |
| Xilem | `xilem` | `run_app!(App)` |
| Floem | `floem` | `run_app!(App)` |

Enabling the `gpui` feature automatically enables `gpui-rsx-classes`, which keeps GPUI subtrees reachable through quoin's `rsx!` escape hatch.

## 3. Wire up code generation

Create `navi.config.json` in your project root (see the [config reference](/reference/navi-config/) for every key):

<Code lang="json" code={`{
  "routes_directory": "./src/routes",
  "generated_route_tree": "./src/route_tree.gen.rs",
  "route_token": "route",
  "index_token": "index",
  "route_file_ignore_prefix": "-"
}`} />

Then call the generator from `build.rs`:

<Code lang="rust" code={`fn main() {
    let config = navi_codegen::NaviConfig::from_file("navi.config.json")
                    .expect("Failed to read config");
    navi_codegen::generator::write_route_tree(&config).unwrap();
}`} />

## 4. Verify

Build the workspace and confirm the generated file appears:

<Code lang="bash" code={`cargo build
ls src/route_tree.gen.rs`} />

The generated module exposes `build_route_tree()` and `register_routes()`, which you use to boot the router — see [Getting Started](/tutorials/getting-started/#4-boot-the-app) for the full bootstrap.
